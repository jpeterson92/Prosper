# Future local application interface

Documentation-only placeholder. There is no web application or CLI.

The adopted investor interface is a local browser application for import readiness, portfolio/lot inspection, plan comparison, manual execution worksheet and reconciliation. Use React/TypeScript/Vite with a typed FastAPI boundary; exact versions remain to qualify. Evaluate Tauri 2/Python-sidecar packaging after workflow acceptance; evaluation approval is not a prequalified installer selection. See [technology alternatives](../docs/architecture/TECHNOLOGY_TRADEOFFS.md). A thin diagnostic CLI may support development, but the end user should not need to program or use a terminal for routine portfolio reviews.

All financial calculations belong in the shared core described in the [architecture](../docs/architecture/ARCHITECTURE.md).
