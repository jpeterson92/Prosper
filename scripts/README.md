# Future development tooling

`dev.ps1` provides `bootstrap`/`sync`, ordinary `dev`/`test`/`docs`, and explicit full `check`/`checkpoint`/`package` operations; `check_project.py` validates authored text, local links and the supplemental manifest. `run_tests.py` supplies testmon-based affected selection, focused/last-failed modes, default `-n auto`, full-result reuse and ignored timing/identity reports. `pytest_workflow.py` records per-test execution and excludes already-run child-process cases. Full baseline creation occurs only at an explicit checkpoint. See the [development guide](../docs/engineering/DEVELOPMENT.md) for commands and [workflow evidence](../docs/tasks/TEST_WORKFLOW.md) for targeted qualification/full-suite deferral. The helpers use project-local environments and restore caller settings; no system-wide runtime or global setting is changed.

`measure_imports.py` generates a deterministic fictional 100-stock/2,000-lot checkpoint, checks it with an independent rational-number oracle and records separate parse/inspection/durable-preview observations. It requires a new output directory under this checkout's ignored `.local` tree and never activates a checkpoint. See [T004.5.2](../docs/tasks/T004.5.2-import-measurements.md) for the exercised command, timing boundaries and evidence.

A future read-only environment diagnostic should verify prerequisites without installing software, changing credentials or reading real portfolios. Build/test commands should be reproducible and synthetic-only. Release, migration and brokerage operations need separate explicit scope.

`qualify_numerics.py --output .local/numerical-probe-<new-id>` exercises the pinned numerical stack with synthetic fixed-state scalar likelihoods, analytical eigensystems and constrained quadratic optima. It writes hashed input/environment/source evidence to a new ignored directory. It performs no market acquisition or risk-model fit. See the [stack/reference report](../docs/tasks/T006.2.1.2-python-stack-reference.md) for conventions, tolerances and qualification limits.
