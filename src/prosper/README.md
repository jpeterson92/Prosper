# Financial/application core boundary

## Advisory analytical entry points

New advisory work uses `basket.estimate`, `equity_benchmark.estimate` and `industry.estimate`: explicit Float64 estimates, Polars valuation/alignment/grouping, scoped unknowns and a shared covariance diagnostic kernel. `advisory.py` supplies bounded decimal parsing and the small whole-share/loss-sign/cash checks; source quantity/basis strings are preserved, without universal fractional-place limits. Numerical reconciliation tolerance is separate from economic limits; unresolved exposure endpoints are review-required rather than silently relaxed.

Run [qualify_advisory.py](../../scripts/qualify_advisory.py) for the fictional benchmark -> basket -> exposure/TE consumer and near-boundary sale/cash examples. [ADVISORY_NUMERICS](../../docs/engineering/ADVISORY_NUMERICS.md) and [T019](../../docs/tasks/T019-advisory-remediation.md) govern scope. These are library/diagnostic paths; the new advisory storage boundary below can retain their input/output JSON. History and API/browser integration remain T019.4/.6.

New analytics use the estimate paths; .4/.6 update remaining consumers and .7 removes redundant implementations and compatibility-only tests. Preserve the accepted financial/model calculations and material source/security checks, not old transport/representation behavior.

[history_registry.py](history_registry.py) adds an explicitly initialized, append-only `synthetic-history-required-v1` SQLite registry in the isolated history runtime. `HistoryRegistry.initialize(history)` reserves a new registry directory once; `HistoryRegistry(history)` reopens without initialization. `register(id, receipt, expected=selection)` verifies context and every raw dependency, is idempotent for the same immutable link, and refuses replacement. `replay(id)` verifies registry structure plus that dependency; `proof()` validates every registered input and returns the complete deduplicated manifest/raw closure. Row identities, ordered chain/count and exact schema checks detect omissions/corruption without inventing an empty registry. SQLite may recover its hot journal under the shared guard after process exit; proof/replay then use query-only connections. Missing/corrupt/reserved state never reinitializes automatically. [history_coordination.py](history_coordination.py) supplies the guarded OS writer lock shared by public history publication, registration and retention proof; busy operations fail explicitly and process exit releases the lock. `assess_removal(reference)` derives the full required set internally and **always refuses removal**: registered inputs are required, unreferenced bytes may be in flight, and incomplete/busy proof has `required=None`. No liveness timeout, unpin or reclamation is supplied; the separate history recovery API above owns backup/restore. [T006.1.3.2.1 evidence](../../docs/tasks/REMAINING_WORK_PLAN.md#t0061321-execution) owns actual verification and its original component boundary.

[history.py](history.py) implements the closed `synthetic-history-v1` envelope and immutable history publication. Use a dedicated synthetic `RuntimeBoundary` under `.local`; the service creates a guarded `synthetic-history-v1` child runtime and publishes raw dependencies before the manifest. The history publication module supplies no provider/parser, calendar inference, merge, catalog/activation or pruning; separate registry/recovery modules above own synthetic dependency retention/restore.
