## OHLC and regularized-return definitions

Source: P22 equations 4.1/4.7 and 3.2-3.6/Appendix A. At observation `t`, write raw compatible prices as `O,H,L,C`. Define the synthetic preceding close `P = C/(1+r)`, then:

```text
overnight = log(O/P)
range     = log(H/L)
proxy     = (a3/f)*overnight^2 + ((1-a3)/(1-f))*range^2/(4*log(2))
stanh(r,kappa) = tanh(kappa*r/2)
x = stanh(r,kappa)*sqrt(proxy)       # enhanced IDR innovation
```

Require positive prices, `L <= min(O,C) <= max(O,C) <= H`, `0 < f < 1`, `0 <= a3 <= 1`, `kappa > 0`, and finite nonnegative proxy. A zero proxy/zero observation can be valid; an entire unusable/zero-variance series cannot. A synthetic preceding close reconciles a supplied compatible return with current-day raw price units; it does not independently qualify the action evidence. Never add a dividend again to an already total-return-adjusted `r`.

P22 reports `f=0.25`, `a3=0.17` and suggests `kappa=10,000` for decimal returns (`100` for percentage returns). These are attributable research candidates, not adopted Prosper defaults. If returns and proxy square roots are both scaled by `100`, covariance and variance scale by `10,000`, omega scales by `10,000`, and equivalent kappa is divided by `100`. Dimensionless persistence/correlation parameters do not scale.

For the identified returns-only reference use `x=r` with its own shrinkage identity. IDR uses `x` and `x^2` consistently in both stages. P22's ID-only model, per-observation missing-field substitutions and its empirical data exclusions/zero fills are not adopted. ## Volatility, target and DCC likelihood contract

For each stock, conditional variance `v[t]` precedes observation `x[t]`:

```text
v[t] = omega + g*x[t-1]^2 + b*v[t-1]
z[t] = x[t]/sqrt(v[t])
univariate_nll[t] = (log(2*pi) + log(v[t]) + x[t]^2/v[t])/2
```

Mathematical domain: `omega > 0`, `g,b >= 0`, `g+b < 1`; the numerical stationarity margin and bounds must be explicit profile fields. Fitting minimizes the sum of these contributions over a declared likelihood sample. Initial variance(s), their source/derivation, whether the initial term is scored, and any presample treatment must be pinned; none may come silently from `arch` or another optimizer. The unconditional variance `omega/(1-g-b)` is a useful algebraic check, not a substitute for the declared initial state. Invalid parameters/nonpositive variance are domain failures, not successful fits with a convenient finite penalty.

After fitting each univariate stage, form `Z[T,N]`. Estimate the nonlinear covariance target using the shrinkage definition below, then normalize its diagonal to obtain SPD correlation target `Ctarget`. Fit correlation dynamics with the target and univariate paths fixed:

```text
Q[t] = (1-alpha-beta)*Ctarget + alpha*z[t-1]*z[t-1]' + beta*Q[t-1]
R[t] = diag(Q[t])^(-1/2) * Q[t] * diag(Q[t])^(-1/2)
H[t] = diag(sqrt(v[t])) * R[t] * diag(sqrt(v[t]))
```

Require `alpha,beta >= 0`, `alpha+beta < 1`, explicit numerical margin and initial Q/backcast, and strictly positive diagonals/pair determinants throughout the scored sample. This is original DCC, not cDCC. Input order and the list of adjacent pairs `(0,1),...,(N-2,N-1)` are frozen; `N >= 2` is required for DCC fitting. Sorting labels without the arrays is invalid. Reordering the data changes this composite fit; fixed-parameter matrix relabeling is a different test from permutation invariance of fitted parameters.

For standardized pair values `(u,w)` and correlation `rho`, the bivariate negative log-likelihood contribution is:

```text
pair_nll = log(2*pi) + log(1-rho^2)/2
           + (u^2 + w^2 - 2*rho*u*w)/(2*(1-rho^2))
objective = sum_over_scored_t(mean_over_declared_pairs(pair_nll))
```

This follows the bivariate Gaussian density. A19 averages over its pair count and sums time. Full raw-return pair covariance adds fixed univariate log-scale terms; record those offsets when comparing objective values. Sum versus mean, dropped constants, signs and pair counts affect objective tolerances even where an optimum is unchanged. No inverse of the whole covariance history is required by the pair objective.

## Analytical nonlinear-shrinkage computational candidate

Source: P20 equations 4.3-4.9 and A20. Let `S = Z'Z/n = U diag(lambda) U'` with sorted eigenvalues and explicit preprocessing. Let `m = min(N,n)` and take the `m` nonzero eigenvalues `ell`. Structural zero multiplicity is `N-n` when `N>n`. Near-zero/negative classification needs Q02's scale-aware rank tolerance; material negativity, extra rank deficiency or nonpositive required eigenvalues is a refusal, not silent ridge regularization or a dropped name.

Define `h=n^(-1/3)`, `x_ij=(ell_i-ell_j)/(h*ell_j)` and:

```text
K(x) = 3/(4*sqrt(5)) * max(1-x^2/5,0)
J(x) = -3*x/(10*pi)
       + 3/(4*sqrt(5)*pi)*(1-x^2/5)*log(abs((sqrt(5)-x)/(sqrt(5)+x)))
J(+/-sqrt(5)) = -3*(+/-sqrt(5))/(10*pi)
f_i = mean_j(K(x_ij)/(h*ell_j))
g_i = mean_j(J(x_ij)/(h*ell_j))
```

The endpoint is a continuous-limit assignment, not evaluation of `0*log(0)`. Near-endpoint cancellation needs an independently checked stable evaluation, not an arbitrary neighborhood replaced with zero. `J` names the Hilbert kernel here, distinct from conditional covariance `H`.

For `N<n`, with `c=N/n`:

```text
d_i = ell_i / ((pi*c*ell_i*f_i)^2 + (1-c-pi*c*ell_i*g_i)^2)
```

A20's singular candidate for `N>n` uses the positive-spectrum means above and:

```text
g0 = (3/(10*h^2)
      + 3/(4*sqrt(5)*h)*(1-1/(5*h^2))*log((1+sqrt(5)*h)/(1-sqrt(5)*h)))
     * mean(1/ell) / pi
d0 = 1/(pi*((N-n)/n)*g0)                # repeated N-n times
d_i = 1/(pi^2*ell_i*(f_i^2+g_i^2))     # positive-spectrum directions
Sigma_target = U*diag(d)*U'
Ctarget = diag(Sigma_target)^(-1/2)*Sigma_target*diag(Sigma_target)^(-1/2)
```

All required `d`, target diagonals and denominators must be finite and positive. Structural zero-space output uses one shared `d0`, so changing its orthonormal basis must not change the matrix. Apply no QIS/linear-shrinkage substitution. Symmetry/PSD checks are necessary, not accuracy/calibration evidence.

The logarithm/kernel-support restriction is `n > 5*sqrt(5)`, hence integer effective `n >= 12`; source numeric code comments name raw sample size before subtracting preprocessing degrees of freedom. P20's surrounding prose also says `p<12` although the displayed support bound depends on `n`; do not conflate this text with the derived effective-sample restriction or an investor history rule. At `N=n`, A20 takes its first branch, while the paper separates theory and simulations. **Until Q03 disposition, equality is an unsupported candidate case, not a qualified result.** This refusal requirement does not establish a supported production dimensional regime.

## Forecast origin and horizon

With observations through session `T`, the one-step forecast uses `x[T]`, `v[T]`, `z[T]` and `Q[T]` to compute `v1` and `Q1` for `T+1`; normalize Q1 to R1. A19's final in-sample covariance is not this forecast. For a candidate using P22's disclosed approximation, write `s_i=g_i+b_i` for univariate persistence (distinct from shrinkage `g_i`) and `q=alpha+beta`:

```text
v_h = omega_i*sum_{j=0}^{h-2}(s_i^j) + s_i^(h-1)*v1_i
R_h_approx = Ctarget + q^(h-1)*(R1-Ctarget)
D_h_approx = diag(sqrt(v_h))
H_h_approx = D_h_approx*R_h_approx*D_h_approx
V_sum = sum_{h=1}^{L} H_h_approx
V_average = V_sum/L
```

An empty sum at `h=1` is zero. The normalized correlation blend is the explicit candidate interpretation of P22 2.6-2.9; it is an approximation, not an assertion that expectation commutes with Q normalization, square roots or matrix products. Changing to normalized expected-Q recursion defines a separately identified forecast method. Q04 retains independent projection/calibration disposition.

Under ADR-0007's fixed-weight/zero-conditional-mean/cross-day approximation, active weights `a` have cumulative variance `a'V_sum*a`, average daily variance divided by `L`, and annualized variance `252/L` times cumulative variance. Return standard deviations are square roots. The research horizon 21 and trading-year factor 252 are disclosed conventions, not calibrated freshness or investor limits.
