## Implemented contract and review

[local_api.py](../../src/prosper/local_api.py) owns one IPv4 `127.0.0.1` socket, a random default API port and one explicitly optional literal-loopback development port. Host includes the exact API port; Origin must match one allowed origin. Browser same-origin GETs may omit Origin only with `Sec-Fetch-Site: same-origin` and the bearer. Session bootstrap always needs explicit Origin and `X-Prosper-Bootstrap: 1`; repeated bootstrap returns one in-memory per-launch token, avoiding an unbounded session registry. Shutdown invalidates the session and ends the owning process. Restart creates a new token, including when reusing the same API port.

All other paths require the token before routing; cookies, proxy/forwarded headers, opaque/null/foreign origins, missing bootstrap headers and query strings grant no access. CORS preflight only permits the allowed origin, GET/POST and the named headers. No financial routes, Swagger/OpenAPI HTTP resources, WebSocket server or frontend exists. The closed diagnostic model explicitly returns synthetic status and planning readiness false.

Security checks precede reading request bytes. Declared size rejects before waiting; streaming/chunked bytes have the same 2 MiB ceiling, one bounded byte buffer and a three-second whole-body deadline before routing/parser allocation. Header totals and h11 incomplete events have 16 KiB caps. The diagnostic operations reject every nonempty body. Uvicorn disables proxies/access logs/WebSockets and closes connections after responses; h11 transport backpressure and a 16-request concurrency guard bound active processing. [Development instructions](../engineering/DEVELOPMENT.md#protected-synthetic-loopback-runtime) retain exact configuration and threat limits.

Same-agent review found and addressed three concrete issues: accumulating tiny body chunks in a list could amplify allocation overhead (replaced by one bounded bytearray); same-origin browser GETs can omit Origin (explicit Fetch Metadata plus bearer rule); FastAPI's current default can inherit telemetry auto-configuration (explicitly disable tracing/metrics/logs/automatic configuration, exercised under an inherited true setting). No unresolved bounded-scope blocker is known. Independent security review is not claimed.

[HTTP/process tests](../../tests/test_local_api.py) exercise actual sockets and isolated Python server processes: bootstrap/repeat, exact diagnostic model, protected shutdown/port release, exclusive binding and refused local non-loopback-interface access, host/forwarding denial, missing/null/foreign/wrong-port origins, cookie/bearer/method/path rejection, narrow preflight, duplicate and excessive headers, declared/chunked oversize, stalled body timeout, early hostile-origin rejection without body bytes, no WebSocket upgrade, explicit dev origin/adjacent-port denial, same-port restart invalidation and invalid/remote CLI configuration. Captured stdout after the one public-origin line and stderr remain empty. No test prints credentials or uses investor data.
