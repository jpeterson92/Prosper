## Primary source register and equation map

Access date: October 24, 2026 UTC. These are independently revisited publications, not package execution or replication. Equation numbers below refer to the named publication, not an interchangeable working paper.

**S01: [Engle, Ledoit and Wolf (2019), Large Dynamic Covariance Matrices](https://www.econ.uzh.ch/dam/jcr:28fa9939-753e-4f5c-932d-945872f30cfd/jbes_2019.pdf), JBES 37:363-375, DOI 10.1080/07350015.2017.1345683.** Sections 2.2-2.3, equations (2.1)-(2.4), define univariate GARCH, standardized innovations, correlation-targeted DCC and normalization; Section 3 owns nonlinear targeting. In notation used here:

```text
v[i,t] = omega[i] + g[i]*x[i,t-1]^2 + b[i]*v[i,t-1]
s[i,t] = x[i,t] / sqrt(v[i,t])
Q[t] = (1-alpha-beta)*C + alpha*s[t-1]*s[t-1]' + beta*Q[t-1]
R[t] = diag(Q[t])^(-1/2) * Q[t] * diag(Q[t])^(-1/2)
H[t] = D[t] * R[t] * D[t],  D[t] = diag(sqrt(v[:,t]))
```

For the standard reference, `x` is the observed return. The scalable composite-likelihood route uses adjacent pairs rather than all pairs. The paper retains original DCC rather than cDCC. Nonlinear shrinkage estimates the target; it is not an operation applied afresh to every final forecast. Canonical ordering must therefore be frozen with the selected pair list. Likelihood initialization, fitting bounds and executable parity remain unqualified here.

**S02: [De Nard, Engle, Ledoit and Wolf (2022), Large dynamic covariance matrices: Enhancements based on intraday data](https://www.econ.uzh.ch/dam/jcr:5ee13ed0-14df-4562-9beb-086a2d76738f/jbf_2022.pdf), JBF 138:106426.** Equations (3.2)-(3.3) define `stanh(r,k) = tanh(k*r/2)` and its product with the proxy's square root. Appendix A uses regularized returns in **both** stages; ID is distinct. Equation (4.1) supplies synthetic preceding close; (4.7), overnight-inclusive OHLC. Sections 2.2-2.3 locate normalization, fitting and approximate averaged forecasts. The experimental missing-field fallback is not Prosper policy. Percent/decimal scaling changes the smoothing parameter by 100. The article's CC BY-NC-ND notice does not settle software licensing.

**S03: [Ledoit and Wolf (2020), Analytical nonlinear shrinkage of large-dimensional covariance matrices](https://www.econ.uzh.ch/dam/jcr:87976d27-67fa-442b-bceb-8af7a0681ba2/annals_2020.pdf), Annals of Statistics 48:3043-3065, DOI 10.1214/19-AOS1921.** Sections 4.5-4.7 locate the density/Hilbert-transform estimator and recomposition; (4.9) specifies bandwidth.
