Each row retains raw/canonical hashes, source/bundle/profile identity, source/schema/semantics/canonicalization/storage/inspection versions, source cutoff, actual UTC recorded time and the evidence receipt. No update/delete method or SQL book arithmetic exists.

The write boundary reparses/reinspects raw input and compares the claimed validated object before publication. An explicit SQLite transaction verifies an existing row before reuse, or publishes/verifies evidence before inserting a new row. A final evidence/path check precedes commit. Reads reconstruct inspection and compare canonical content and metadata against verified original evidence. Connections close after each operation. Database/journal/WAL/SHM paths reuse runtime guards and reject aliases, nonregular files and hard links. Private-mode integration used only synthetic scratch.
